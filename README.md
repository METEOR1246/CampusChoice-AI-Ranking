# CampusChoice: Explainable and Controllable Event Ranking

**Status:** Planning / Initial repository (7 November 2026)  
**README prose word count:** Approximately 350 words

## Overview

CampusChoice is a proposed interactive prototype for the University of Birmingham's Intelligent Interactive Systems Assignment 2.

It builds on Assignment 1's research question: **How does AI-generated ranking influence users' decision-making and perceived control?**

The project explores how university students interact with ranked event recommendations, and whether explanations and preference controls change their understanding and choices.

## Planned Interaction Modes

1. **Basic Ranking:** Students browse and select from a ranked event list.
2. **Explained Ranking:** The same initial ranking includes an optional "Why recommended?" explanation.
3. **Adjustable Ranking:** Students can modify preference weights, view updated rankings, and reset their changes.

The initial ranking and event dataset will remain consistent across modes to support meaningful comparison.

## Proposed Technical Approach

The initial prototype is expected to use:

- A small local dataset of fictional university events.
- A browser-based interface.
- A transparent ranking and preference-scoring mechanism.
- User interactions and feedback to support evaluation.

The exact technology stack is not yet finalised. A fixed weighted-ranking algorithm will be described accurately as rule-based or simulated ranking unless additional AI inference is implemented.
